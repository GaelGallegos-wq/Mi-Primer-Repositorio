Que es GitHub?
Es una plataforma en la nube que permite a los desarrolladores almacenar, gestionar y colaborar en proyectos de codigo fuente usando el sistema de control de versiones git.
Que espero de aprender a usar repositorios?
Yo espero aprender conceptos esenciales, asi como a crear espacios de trabajo (locales y remotos) donde se almacena todo el historial y los archivos de los proyectos.
Durante el aprendizaje del uso de git hub, espero no estancarme tanto como han pasado con otros programas como python
